# Phase 8: Demonstration Video - EduGenie

## 1. Demonstration Objective
Show the working EduGenie application and its main learning features in a short screen recording.

## 2. Demonstration Flow
1. Show the VS Code project.
2. Show the terminal command used to start FastAPI.
3. Show the EduGenie webpage.
4. Enter a sample educational question/topic.
5. Show the generated result.
6. Briefly show the Quiz, Summary and Explanation features.
7. End with the working EduGenie interface.

## 3. Suggested Short Demo
For a very short submission video, capture:
- Terminal with the running server.
- EduGenie homepage.
- One question and its generated answer/result.

## 4. Local Run Command
```bash
uvicorn main:app --reload
```

http://127.0.0.1:8000
